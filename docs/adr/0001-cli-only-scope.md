# ADR-0001：CLI-only 产品范围

- 状态：Accepted
- 日期：2026-10-31

## 背景

原项目同时包含 WebUI、训练、实时/VST 和多种工具。当前发行目标是可安装、可验证的离线推理工具，不希望这些历史能力继续扩大依赖面或形成错误支持承诺。

## 决策

产品范围限定为统一 CLI 下的 RVC 文件变声和五个固定模型的人声分离。WebUI、训练、实时/VST、PyMSS server、workflow、ensemble 及未保留模型明确不支持，也不提供无实现的兼容空壳。

## 后果

包和 CI 只覆盖 CLI 推理。恢复被排除能力需要新的范围决策、依赖与测试合同；不能通过在当前模块中追加隐藏入口绕过该决策。
